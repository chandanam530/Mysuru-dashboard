# Mysuru Environmental Dashboard (Streamlit)

Login: `admin` / `Mysuru@2026`

## Run on your computer
1. Install Python 3.10+ from python.org (tick "Add Python to PATH").
2. Open a terminal / Command Prompt in this folder.
3. `pip install -r requirements.txt`
4. `streamlit run app.py`
5. Your browser opens at http://localhost:8501

## Put it online free (Streamlit Community Cloud)
1. Upload this folder to a GitHub repository.
2. Go to share.streamlit.io, sign in with GitHub, click "Create app".
3. Choose the repo, branch and `app.py`, then Deploy.
4. (Optional) Change the login: App settings > Secrets, add
   username = "yourname"
   password = "yourpassword"
